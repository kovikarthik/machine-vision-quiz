CECS 553 Quiz 1 Formula & Concept Cheat Sheet

📐 Spatial Output Formula

O = ⌊(W - K + 2P) / S⌋ + 1
  • W: Input width / height
  • K: Kernel / Filter dimension
  • P: Padding (P=0 for Valid, P=(K-1)/2 for Same)
  • S: Stride (step size)

🔢 Conv Parameter Counting

Params = (K_w × K_h × C_in + 1) × C_out
  • Weights: K_w × K_h × C_in × C_out
  • Biases: 1 per output filter (= C_out)
  • Max/Avg Pooling: Exactly 0 parameters!

⚡ Activation Functions & Ranges

  • Sigmoid: σ(z) = 1/(1+e^-z) • Range: (0, 1) • Max deriv: 0.25
  • Tanh: tanh(z) = (e^z-e^-z)/(e^z+e^-z) • Range: (-1, 1) • Zero centered
  • ReLU: max(0, z) • Range: [0, ∞) • Deriv: 1 (z>0), 0 (z≤0)
  • Leaky ReLU: max(0.01z, z) • No dying ReLU problem!
  • Softmax: e^z_i / Σ e^z_j • Multi-class outputs sum to 1

🛡️ Overfitting & Regularization

  • Dropout: Random zeroing during training; scale by (1-p) at test time.
  • Batch Norm: y = γ * ((x-μ)/√(σ²+ε)) + β • speeds convergence.
  • L1 Regularization: Penalizes Σ|w|, induces weight sparsity.
  • L2 Weight Decay: Penalizes ½Σw², shrinks weights smoothly.
  • Data Augmentation: Random flips, crops, rotations to expand support.

🏛️ Classic CNN Milestones

  • LeNet-5 (1998): 5 layers, Tanh/Sigmoid, checks & MNIST.
  • AlexNet (2012): 8 layers, ImageNet winner, introduced ReLU, Dropout, GPUs.
  • VGG (2014): Stacks of 3x3 filters (two 3x3 = 5x5 receptive field, fewer params).
  • ResNet (2015): Residual connections H(x) = F(x) + x, solves vanishing gradients.

🎯 Vision Tasks Hierarchy

  • Classification: Single label for entire image.
  • Object Detection: Bounding box [x, y, w, h] + class label (YOLO, R-CNN).
  • Semantic Segmentation: Classify every pixel without instance distinction.
  • IoU Metric: Area(Overlap) / Area(Union) • True positive if IoU ≥ 0.5.
